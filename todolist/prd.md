# Todoistly PRD

## 1. 제품 개요
작은 하루의 할 일을 빠르게 기록하고 완료 상태를 관리하는 반응형 Todo List 웹사이트다. 설치 없이 브라우저에서 실행되며 데이터는 사용자의 브라우저에 보관한다.

## 2. 목표
- 할 일을 10초 안에 추가한다.
- 오늘 해야 할 일과 완료한 일을 한 화면에서 확인한다.
- 모바일과 데스크톱에서 같은 흐름으로 사용한다.

## 3. 핵심 사용자
- 개인의 하루 업무와 생활 심부름을 관리하는 사용자
- 별도 회원가입 없이 가볍게 쓰고 싶은 사용자

## 4. 핵심 기능
1. 할 일 추가: 제목을 입력하고 Enter 또는 추가 버튼으로 등록한다.
2. 완료 토글: 체크박스로 완료/미완료를 전환한다.
3. 삭제: 각 항목을 개별 삭제한다.
4. 보기 필터: 전체, 진행 중, 완료 항목을 전환한다.
5. 검색: 제목 기준으로 목록을 즉시 검색한다.
6. 통계: 전체, 진행 중, 완료 개수를 표시한다.
7. 완료 항목 일괄 삭제: 완료된 항목만 한 번에 삭제한다.
8. 영속성: 새로고침 후에도 localStorage에 저장된 목록을 복원한다.

## 5. 사용자 경험 요구사항
- 빈 목록에는 다음 행동을 안내한다.
- 완료 항목은 취소선과 낮은 대비로 구분한다.
- 조작 가능한 버튼에는 접근 가능한 이름을 제공한다.
- 입력창, 버튼, 필터는 키보드로 사용할 수 있다.
- 화면은 파스텔톤을 사용하되 본문 텍스트는 충분한 대비를 가진다.

## 6. 성공 기준
- 사용자가 새 할 일을 추가하고 완료 처리할 수 있다.
- 필터와 검색 결과가 현재 목록과 일치한다.
- 새로고침 뒤 목록과 완료 상태가 유지된다.
- 375px 이상의 모바일 화면에서 가로 스크롤 없이 사용할 수 있다.
